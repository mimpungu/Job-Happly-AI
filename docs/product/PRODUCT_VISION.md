# Vision produit — Happly AI

Happly AI est un assistant personnel de recherche d'emploi qui centralise et automatise les étapes d'une candidature : trouver des offres sur plusieurs sources autorisées, les normaliser et éliminer les doublons, les comparer au CV maître avec un score explicable, générer un CV LaTeX et une lettre sur mesure, suivre les candidatures, puis préparer les entretiens.

## Principes

- **Véracité** : aucune information inventée ; tout fait généré est traçable jusqu'au CV maître.
- **Contrôle de l'utilisateur** : l'IA assiste, ne décide jamais ; aucune candidature n'est envoyée automatiquement.
- **Maîtrise des coûts** : API IA payante toujours plafonnée, cache, traitement sans IA d'abord.
- **Sources honnêtes** : gratuites et publiques, jamais de contournement ; couverture affichée sans exagération.
- **Confidentialité** : données locales, envoi minimal et consenti vers l'IA.
- **Robustesse** : produit durable, pas un prototype ; tests, sécurité et documentation dès le départ.

## Usage actuel

Application locale, mono-utilisateur, sans authentification (ADR-0008). Partage et hébergement distant ultérieurs.
